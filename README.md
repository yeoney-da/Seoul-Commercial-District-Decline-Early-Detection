# Seoul-Commercial-District-Decline-Early-Detection
Early detection of commercial district decline in Seoul using public data and a Business Vitality Index (BVI)
# 도시의 신호를 읽다: 서울시 상권 쇠퇴 징후 감지 및 BVI 구축

**서울시 공공데이터를 활용하여 상권별 쇠퇴 징후를 분석하고, Random Forest 기반 쇠퇴 위험 분류 모델과 상권건강도지수(BVI)를 구현한 프로젝트입니다.**

## 1. 프로젝트 개요

- **주제:** 서울시 상권 쇠퇴 징후 감지 및 상권건강도지수(BVI) 구축
- **분석 대상:** 2025년 서울시 상권 데이터
- **활용 데이터:** 서울시 상권 마스터, 점포-상권, 집객시설-상권 CSV
- **분석 도구:** Python, Pandas, NumPy, Scikit-learn
- **핵심 방법론:** Feature Engineering, Shannon Entropy, Random Forest

## 2. 문제 정의

상권의 쇠퇴를 매출 감소나 폐업 증가 이후에 파악하는 것이 아니라, 점포 구성과 상권 환경의 변화에서 나타나는 징후를 활용해 사전에 파악하고자 하였습니다.

이를 위해 서울시 공공데이터를 결합하고, 상권별 특성을 반영한 지표를 생성하여 쇠퇴 위험을 분류하는 분석 파이프라인을 구축하였습니다.

## 3. 데이터 분석 및 전처리

### ① 데이터 수집 및 통합
- 서울시 상권 마스터, 점포-상권, 집객시설-상권 데이터 로드
- 상권 코드 및 기준년분기를 기준으로 데이터 결합
- 상권별·분기별 점포 현황 집계

### ② Feature Engineering
- 폐업률 및 개업률 산출
- 프랜차이즈 점포 비율 산출
- 개·폐업 점포 수를 활용한 점포 생존 압력 지수 설계
- Shannon Entropy를 활용한 상권별 업종 다양성 측정
- 집객시설 및 교통 접근성 관련 변수 결합

## 4. 머신러닝 기반 쇠퇴 위험 분류

- 2025년 1~3분기 데이터를 선행 변수로 활용
- 2025년 4분기 폐업률 상위 20%를 쇠퇴 위험 상권으로 정의
- Random Forest Classifier를 활용한 이진 분류 모델 구현
- ROC-AUC를 통한 학습 데이터 내 분류 결과 확인
- Feature Importance를 활용한 주요 변수 영향도 분석

## 5. 상권건강도지수(BVI) 구축

모델의 쇠퇴 위험 예측 확률을 활용하여 상권건강도지수(BVI)를 산출하였습니다.

- BVI = (1 - 쇠퇴 위험 예측 확률) × 100
- 70점 이상: 안전
- 40점 이상 70점 미만: 주의
- 40점 미만: 위험

이를 통해 상권별 건강도 등급을 구분하고, BVI가 낮은 상권을 중심으로 쇠퇴 위험 상권을 탐색할 수 있도록 구성하였습니다.

## 6. 주요 결과물

- 상권별·분기별 분석 데이터
- Random Forest 기반 쇠퇴 위험 분류 모델
- Feature Importance 분석 결과
- 상권별 BVI 및 건강도 등급
- 쇠퇴 위험 상권 목록 CSV

- 상권 특성을 반영한 파생변수 설계
- Shannon Entropy 기반 업종 다양성 분석
- Random Forest 분류 모델 구현
- 머신러닝 예측 결과를 활용한 지수 설계
